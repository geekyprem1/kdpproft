## Why books get rejected (simple truth)

Amazon isn’t trying to bully you.  
Most failures come from mismatches:

- Trim size doesn’t match  
- Cover built for wrong page count  
- Content too close to edges  
- Low-quality / misleading listing  
- Incomplete or wrong file uploaded  

KDP Mafia builds Amazon-friendly files — this guide is your **human final pass**.

Flip through the PDF:

### D) Cover quality scan

- [ ] Title readable at thumbnail size  
- [ ] Book type readable  
- [ ] Niche visually obvious  
- [ ] Author name correct  
- [ ] No important text in barcode area  
- [ ] Spine text only if page count supports it  
- [ ] No blurry / stretched artwork  
- [ ] No trademarks / logos / celebrity faces  

### E) Listing honesty scan

- [ ] Title matches contents  
- [ ] Age range matches contents  
- [ ] Description doesn’t overclaim  
- [ ] No brand IP  
- [ ] Keywords relevant (Bonus #4)

## Part 2 — Paperback upload flow (step by step)

1. Go to [kdp.amazon.com](https://kdp.amazon.com)  
2. Create → Paperback  
3. Enter language, title, subtitle, author  
4. Paste description (Bonus #4 framework)  
5. Set publishing rights  
6. Choose 2 categories  
7. Fill all 7 keywords  
8. Set age/grade if needed  
9. Continue to print options  
10. Select trim size / ink / paper to match your files  
11. Upload manuscript (interior PDF)  
12. Upload cover  
13. Launch **Print Previewer**  
14. Inspect cover wrap + interior thoroughly  
15. Fix issues → re-upload → preview again  
16. Set territories + pricing  
17. Publish (or save draft if account/tax still pending)

## Part 3 — Common rejections & exact fixes

### Error 1 — Trim size / manuscript size mismatch

**What it means:** Interior PDF size ≠ trim selected in KDP.  

**Fix:**
1. Check notes for intended trim  
2. Confirm KDP Mafia export trim  
3. Re-generate/re-export at correct trim if needed  
4. Re-upload interior  
5. Make sure KDP form trim matches  

**Prevent:** Write trim in `notes.txt` before generating cover.

---

### Error 2 — Text/images cut off or outside safe area

**What it means:** Content too close to edges, or bleed expected but missing.  

**Fix:**
1. Identify if the book should have bleed (full-bleed coloring) or not  
2. Regenerate with standard/safe settings in KDP Mafia  
3. Don’t randomly “scale to fit” in unknown PDF tools  
4. Re-preview  

**Prevent:** For text/puzzle books, keep content clearly inside margins.

---

### Error 3 — Cover size incorrect / spine width wrong

**What it means:** Cover was built for a different page count or trim.  

**Fix:**
1. Note final interior page count after generation  
2. Regenerate cover in KDP Mafia using that exact count + trim  
3. Replace cover file  
4. Preview wraparound carefully  

**Prevent:** Never reuse an old cover on a longer/shorter book.

---

### Error 4 — Image quality too low

**What it means:** Soft, pixelated, or stretched images.  

**Fix:**
1. Regenerate cover/pages in KDP Mafia  
2. Avoid enlarging tiny images in editors  
3. Use tool-native exports  
4. Re-upload  

**Prevent:** Don’t screenshot pages and upload screenshots as interiors.

---

### Error 5 — Blank pages / missing content

**What it means:** Incomplete generation or bad download.  

**Fix:**
1. Re-open preview in KDP Mafia  
2. Confirm generation finished  
3. Download fresh files  
4. Re-upload  

**Prevent:** Wait for job completion before downloading.

---

### Error 6 — Hard-to-read text

**What it means:** Tiny fonts, low contrast, busy backgrounds.  

**Fix:**
1. Use large-print / beginner settings where claimed  
2. Simplify cover: big title, high contrast  
3. Remove fancy fonts that break at small sizes  

**Prevent:** Do the thumbnail test before upload.

---

### Error 7 — Metadata / listing rejected

**What it means:** Title/description/keywords violate rules or look misleading.  

**Fix:**
1. Remove trademarks and celebrity names  
2. Make title match real contents  
3. Remove income/medical miracle claims  
4. Resubmit  

**Prevent:** Use Bonus #4 formulas and stay honest.

---

### Error 8 — Wrong interior type (color vs B&W)

**What it means:** Color content uploaded as B&W (or opposite expectations).  

**Fix:**
1. Decide if the book truly needs color  
2. Match KDP interior type to files  
3. Re-upload if necessary  

**Note:** Color costs more and changes pricing math. Use intentionally.

---

### Error 9 — Barcode / back cover issues

**What it means:** Important text where barcode sits, or messy back cover.  

**Fix:**
1. Keep lower-right / barcode zone clean  
2. Regenerate cover if text collides  
3. Preview back cover specifically  

---

### Error 10 — “Something went wrong” upload failures

**What it means:** File corrupt, too large, browser glitch, or incomplete download.  

**Fix:**
1. Re-download from KDP Mafia  
2. Try another browser  
3. Disable flaky extensions  
4. Re-upload one file at a time  
5. Confirm PDF opens locally first

## Part 4 — Print Previewer green-light checklist

Do not publish until every box is checked:

- [ ] Previewer opens with no blocking errors  
- [ ] Front cover looks correct  
- [ ] Spine looks correct (or correctly blank if too thin)  
- [ ] Back cover looks correct  
- [ ] Barcode area clear  
- [ ] First interior page correct  
- [ ] Middle pages consistent  
- [ ] End pages / answer key complete  
- [ ] No clipped art/text in preview  
- [ ] You’re okay with the thumbnail look  

**If even one box fails → fix first.**

---

## Part 5 — Debug order when you’re stuck

Change one thing at a time:

1. Confirm trim + page count match everywhere  
2. Re-download fresh files from KDP Mafia  
3. Re-upload interior only → preview  
4. Re-upload cover only → preview  
5. Regenerate cover with exact page count  
6. Regenerate full book only if needed  
7. Simplify listing metadata if KDP flags content policy  

Frustration usually comes from changing 5 variables at once.

## Part 12 — FAQ

**Q: Do I need ISBN on day one?**  
A: KDP can provide a free ISBN for paperbacks. Follow current KDP options in the form.

**Q: Can I publish while tax interview is pending?**  
A: You can often prepare drafts/files; full publishing may require account setup complete.

**Q: Should I use KDP Cover Creator instead?**  
A: Prefer your KDP Mafia cover so trim/spine stay matched to your workflow.

**Q: Hardcover on day one?**  
A: Not necessary. Paperback first.

**Q: My previewer warning seems minor.**  
A: Read it anyway. “Minor” warnings can still block approval.

**Q: How many times should I regenerate?**  
A: Once for content issues, once for cover page-count sync. If still broken, simplify niche/settings.
