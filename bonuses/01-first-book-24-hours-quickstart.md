## Hour 1–3 — Generate inside KDP Profit Machine

### Step-by-step

1. Open KDP Profit Machine dashboard  
2. Select your book type  
3. Enter the theme/niche **exactly as you’ll sell it**  
4. Use beginner-safe settings:

| Setting | Starter choice | Why |
|---------|----------------|-----|
| Pages / puzzles | 40–60 (or tool default ≥ 24) | Above KDP minimum, not huge |
| Difficulty | Easy → Medium | Fewer complaints / returns |
| Age group | Match niche | Listing stays honest |
| Answer key | ON for puzzles | Expected by buyers |
| Trim | 8.5×11 puzzles/coloring; 6×9 journals | Common + safe |

5. Click **Generate**  
6. Wait for the job to finish — do **not** start a second book yet  
7. Preview sample pages carefully

### Preview QA (do not skip)

- [ ] Theme matches what you typed  
- [ ] No cut-off words / puzzles  
- [ ] Pages aren’t randomly blank in the middle  
- [ ] Answer key exists (puzzle books)  
- [ ] Looks intentional, not empty junk  

**If something’s wrong:** regenerate **once** with a clearer theme.  
**If still wrong:** switch to a simpler niche from the Fast-Start list — don’t spiral.

## Cover session (30–60 minutes)

### Cover job #1: thumbnail test

Shrink the cover on your screen until it’s tiny. Can you still read:

- [ ] Main title?
- [ ] Book type (Word Search / Coloring / etc.)?
- [ ] Niche theme?

If not → bigger title, less decoration.

### Cover checklist

- [ ] Niche is visually obvious  
- [ ] No tiny paragraph text on the front  
- [ ] High contrast (dark on light or light on dark)  
- [ ] Author name correct  
- [ ] No trademarked characters / logos  
- [ ] Cover regenerated with **final page count** (spine depends on pages)

### Cover formula that works

**Big theme word** + **book type** + simple relevant image.

Examples:
- CUTE CATS — Word Search Puzzle Book  
- EASY SUDOKU — Large Print  
- DINOSAUR MAZES — For Kids

## Hour 4–6 — Amazon KDP upload walkthrough

### Create the title

1. Go to KDP → **Create** → **Paperback**  
2. Language = English (or your market)  
3. Book title = final title  
4. Subtitle = audience + benefit (not keyword spam)  
5. Author = your pen name  
6. Description = use framework from Bonus #4  
7. Publishing rights = you own the rights  
8. Categories = 2 strong ones (Bonus #4)  
9. Keywords = all 7 slots (Bonus #4)  
10. Age / grade if relevant (kids books)

### Upload files

1. Upload manuscript (interior PDF)  
2. Upload cover  
3. Open **Print Previewer**  
4. Flip front → middle → end → cover wrap  
5. Note any errors → fix with Bonus #5  
6. Re-upload only what changed  
7. Preview again until clean  

### Pricing starter guide

| Book type | Starter paperback price |
|-----------|-------------------------|
| Word search / sudoku / maze | $6.99 – $8.99 |
| Coloring / activity | $7.99 – $9.99 |
| Journal / tracker | $6.99 – $9.99 |

Day one goal is **publish**, not max royalty optimization.

## FAQ — day one

**Q: My book is still generating.**  
A: Wait. Don’t open 5 parallel jobs on day one.

**Q: Previewer shows a warning.**  
A: Open Bonus #5 and fix the matching issue. Re-upload.

**Q: Should I run ads today?**  
A: No. Publish first. Ads after you have 3–5 solid books.

**Q: Paperback or ebook?**  
A: Paperback first for puzzles/low-content. Add Kindle later if it fits.

**Q: What if KDP account isn’t approved yet?**  
A: Finish files + draft today. Publish when account is cleared.

**Q: Can I use ChatGPT to rewrite the description?**  
A: Yes for polishing — but keep it honest and specific to YOUR book.
