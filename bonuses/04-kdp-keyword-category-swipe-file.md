7. Kids books: age range should match content

## Part 6 — Category direction guide

Exact browse paths change inside KDP. Start near these and pick the deepest true fit.

### Puzzle books
- Crafts, Hobbies & Home → Puzzles & Games  
- Humor & Entertainment → Puzzles & Games  
- Children’s Books → Activities / Puzzles  

### Coloring
- Children’s Books → Arts & Crafts / Coloring  
- Arts & Photography → Drawing → Coloring Books  
- Crafts, Hobbies & Home → Crafts for Children  

### Journals / trackers
- Self-Help → Journal Writing  
- Crafts, Hobbies & Home → Scrapbooking & Journals  
- Religion & Spirituality → Worship & Devotion *(faith only)*  

### Kids learning
- Children’s Books → Education & Reference  
- Children’s Books → Activities  
- Education & Teaching → Studying & Workbooks  

### Specialty
- Sports / outdoors related journals → closest hobby category that is still honest  
- Humor gift puzzles → puzzles/games before random humor categories  

**Rule:** Specific and accurate beats broad and spammy.

## Part 10 — Common listing mistakes

| Mistake | Fix |
|---------|-----|
| Title is clever but unclear | Say theme + book type plainly |
| Keyword slots half empty | Use packs A–I |
| All 7 slots are holiday words | Mix evergreen + seasonal |
| Description is one giant block | Use short paragraphs + bullets |
| Category is random | Use deepest accurate path |
| Subtitle repeats whole title | Add audience/benefit only |
| Using famous brand names | Remove immediately |

## Appendix — Description polish checklist

After drafting your description:

- [ ] First 2 lines make sense without clicking “read more”  
- [ ] Book type is mentioned early  
- [ ] Audience is mentioned early  
- [ ] Bullets are specific (not fluff)  
- [ ] No fake urgency (“buy now before we take it down”)  
- [ ] No guaranteed income language  
- [ ] No medical cure claims  
- [ ] No trademarked character names  
- [ ] Call-to-action at the end is simple  

### Weak vs strong bullets

Weak:
- Amazing puzzles  
- Great for everyone  
- High quality book  

Strong:
- 50 large-print cat-themed word searches  
- Answer key included for every puzzle  
- Perfect gift for cat lovers and cozy puzzle fans  

Write like a human helping a shopper decide in 10 seconds.
