- Topic → outline → chapter-by-chapter, **voice-locked** manuscript

- Typographic cover + metadata
- Export: **EPUB, DOCX, print-ready PDF**

### 5.7 Cover Studio
- **3 distinct, professionally-scored cover concepts** per book
- AI art + genre-aware typography
- Regenerate any concept
- Export KDP-ready wraparound PDF (correct spine + bleed) or PNG

### 5.8 Launch Kit™
Per book, zipped with interior + cover:
- 7 primary + 20 long-tail keywords
- Category recommendations
- AI-written description
- Alternative titles
- `metadata.json`
- Publish checklist

### 5.9 Production & vaults
- **Background jobs** — close laptop; generation continues
- Production Queue — live progress + one-click retry
- **Publishing Vault™** — all books
- **Asset Vault** — all generated files

### 5.10 Compliant-by-construction PDF engine
- Trim sizes 5×8 → 8.5×11
- Bleed 0.125"
- Gutter margins scale with page count
- Spine width from page count + paper stock
- Auto-padded to KDP **24-page minimum**
- Validated against Amazon’s real Print Previewer (zero errors on samples)
